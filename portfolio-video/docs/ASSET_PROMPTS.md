# Optional Asset Upgrades

Nothing here blocks the build. Every slot has a code-drawn fallback that ships by default.

## 1. Headshot → identity beat (Frame 2)
- A high-resolution photo (≥ 2000 px on the short side), plain or dark background, looking at the camera, neutral or slight smile.
- It's treated as a duotone (ink + signal) inside the HUD brackets for about 0.75 s before the 3D name.

## 2. Screen recordings → proof beats (Frames 4–7)

  - PrediCT Studio running a scan and showing the lesion table
  - Convo-Ease flagging a message
  - Copilot-for-DS turning a prompt into a model
- Each becomes a picture-in-picture "monitor" with a mask reveal, behind the numbers.
